Review 2 · Causality-aware PINN-MPC · 4

The key design change since Review 1: a scalar initial condition cannot carry a whole profile from one hop to the next, so each profile is encoded with Legendre coefficients and re-encoded after every hop. The whole 8-hop chain is differentiable, so the optimiser gets exact gradients in one reverse pass instead of extra simulations.
